Frequently Asked Questions

Normal mode uses a simplified method of searching. Whatever you search for is what it will look for, with some caveats. It will trim out punctuation and it will ignore capitalization. The order of the words matters too, so searching for "Did I mine that" will not find results for "I did mine that". The words you search for must come one after another in the caption, so searching for "one two three" will not find results for "one two and three".

Expert mode gives you a lot more control, but is harder to learn. You can refer to the SQLite Full Text Search documentation to understand how it works under the hood and see all the possible options. Alternatively, you can learn by messing with these example search terms.
  • First of all, if you use single or double quotes in your search term, you'll need to escape them by doubling them up. You may also need to wrap the whole search term in double quotes sometimes. Example: """I''ll be back"", The wild Dunk thinks."
  • kill OR butt - will return captions with "kill", captions with "butt", and captions with "kill butt"
  • switch NOT nintendo - will find captions with the word "switch" but not "nintendo"
  • Ninten* - will find words with "Ninten" as the prefix, like "Nintendo" and "Nintendogs"
  • kill* NOT kill - you can combine filters, and in this case it will return captions with "killed" or "kills" but not "kill"
  • Try using the optional filters to narrow down the results
  • Try searching for a key word or 2 instead of an entire quote. Sometimes different words have better results.
  • Try alternate spellings of words, since sometimes the auto-generated captions aren't quite right.
  • If the quote was broken into multiple captions, such as "I'll have the spaghetti" and "and meatballs", then you may need to try searching for just one part of the quote.
  • For videos with auto-generated subtitles, certain swear words are replaced with [ __ ] which is not searchable. If your search term includes a swear and the captions are auto-generated, then you likely won't be able to find the quote without changing your search term.
  • Some videos are not able to be searched. See the Are there any unsupported videos? question below.
  • You can try using a tool like DB Browser for SQLite to open the database file and directly inspect and query the data.
  • If you still cannot find a quote, try asking in the Weekly Search Megathread on the videogamedunkey subreddit.
  • I used JavaScript to extract the captions from all of Dunkey's YouTube videos and stored them in JSON files. I then processed these captions and inserted them into a database to make them easily searchable.
  • At first, I stored all these captions in a PostgreSQL database and used Full Text Search for quick searching. I also used a Linux droplet on DigitalOcean to host a .NET web app for interfacing with this database.
  • I later rebuilt the site as a static website to save money, so now it uses a SQLite database with Full Text Search. Everything else is pure HTML, CSS, and JavaScript.
  • Search results are sorted in order of video upload date, then by the timestamp in the video.
  • YouTube doesn't actually have an API for downloading captions from other people's videos. At one point I had an automated process that could update the site with new video captions on a nightly basis, but it was a hack that stopped working when YouTube updated their security. It wasn't worth trying to fix it every time YouTube broke it, so now I manually run some JavaScript to extract captions. This means sometimes the site is out of date.
  • You can view all the source code here to learn more.
